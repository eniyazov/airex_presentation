# PMD Group – Airex Expo opening presentation

Live presentation for the stage LED screen (4608 × 1024 px).

Open the page, press **F** for full screen, then:
- **→ / PageDown / Space / click** – next slide
- **← / PageUp** – previous slide
- **B** – black screen, **Home** – restart

Starts on a black screen. Each slide plays its animation once, then only the map pulses continue until the next press.
